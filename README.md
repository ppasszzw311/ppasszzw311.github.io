## 總覽

本操作手冊主要針對使用我們的ProxyOne產品的管理者進行相關設定及管理的說明。頁面部分可能會因為不同客制化而有些部分不同，本手冊是依據產品最主要之功能及設定模組進行說明。

各項功能實際操作可參閱以下各頁面說明其設定及操作方式。若參閱本操作手冊後仍有疑問請洽＿＿＿＿

----

快速預覽與部署

- 在本地預覽：在專案根目錄執行一個簡單的靜態伺服器，例如使用 Python 3 的 http.server：

```bash
# 在 repo 根目錄執行，macOS / zsh
python3 -m http.server 8000
# 然後打開瀏覽器 http://localhost:8000/ 查看
```

- 建議：將本 repo 的 `main` 分支設定為 GitHub Pages 的發佈來源 (Repository > Settings > Pages)，以便使用 `index.html` 作為網站首頁。

----

我已新增一個簡單的履歷首頁 `index.html` 及樣式 `assets/css/resume.css`，你可以把想要突出的作品（例如 `demo/` 或 `otherproject/` 中的代表專案）內容搬到 `index.html` 中或建立獨立頁面連結回來。

若要我幫你把特定作品的內容整理到這個首頁（例如挑選 3 個代表專案並補描述與截圖），告訴我你想展示的專案路徑與一段簡短說明，我會代為整理。
