# Pablo Chen Portfolio (GitHub Pages)

這個 repo 是我的個人作品入口，主軸是「全端 / 後端工程能力」。

## 快速預覽

```bash
python3 -m http.server 8000
```

開啟 `http://localhost:8000/`。

## 目前內容

- `index.html`：履歷首頁（技能、工程方法、代表作品、技術證據）
- `assets/css/resume.css`：首頁樣式
- `demo/`：即時看板展示
- `otherproject/`：歷史專案集合

## 下一步補件建議（高優先）

1. **API 證據**：補兩支 API 的 request / response / error code。
2. **DB 證據**：補 schema 與索引策略（至少一個核心資料表）。
3. **維運證據**：補 CI/CD、告警、回滾與故障排除流程。
4. **成果證據**：補可量化數字（延遲、可用性、效率）。
