# Pablo Chen Portfolio (GitHub Pages)

這個 repo 目前作為我的個人作品入口，目標是以「全端 / 後端工程能力」為主軸，逐步把過去專案整理成能清楚呈現工程價值的技術履歷。

## 快速預覽

```bash
python3 -m http.server 8000
```

開啟 `http://localhost:8000/`。

## 目前內容

- `index.html`：新版履歷首頁（工程定位、技能、方法、作品、補強建議）
- `assets/css/resume.css`：首頁樣式
- `demo/`：即時看板展示
- `otherproject/`：歷史專案集合

## 建議後續補齊（讓 repo 更有說服力）

1. **專案說明模板一致化**：每個代表專案至少有「背景 / 技術 / 職責 / 結果」四段。
2. **Backend 實務證據**：補 API spec、DB schema、錯誤碼與資料流。
3. **維運能力展示**：補 CI/CD、監控告警、故障處理與回滾策略。
4. **可量化成果**：例如效能提升%、回應時間、故障率下降等指標。
5. **聯絡資訊完整化**：更新 Email、LinkedIn、技術文章或演講連結。

## GitHub Pages 建議設定

- Branch：`main`
- Folder：`/ (root)`
- Homepage：`index.html`
